# Image attribution

Every image in `frontend/public/images/places/` comes from Wikimedia Commons
under a Creative Commons Attribution-ShareAlike licence. Attribution is a
condition of use: the credit must appear wherever the photo is displayed.

The API serves this as `images[].credit` on each place. Don't drop it.

Images were downloaded 2026-08-20 at 1200px. Licences were checked at that
time; a file's licence on Commons can change, so re-check before publishing.
